# Brand assets

All logos on the website are drawn from the **official Pixel Graphics logo artwork**
(supplied Illustrator file `dark_bg.pdf`). The exact vector paths live in
`src/components/logoArt.ts` and were checked pixel-for-pixel against the source file.

- `logo-mark.svg`: the PX symbol (for use on a dark background)
- `logo-lockup-dark.svg`: the horizontal lockup PX | PIXEL GRAPHICS (for use on a dark background)
- `pattern-dark.svg`: the diagonal brand pattern

Do not redraw, stretch or recolour the logo. Use only the approved versions from the brand guide.
