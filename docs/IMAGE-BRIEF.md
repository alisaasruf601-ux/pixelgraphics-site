# Image brief — photography to replace the illustrated visuals

The site currently uses brand-built SVG illustrations (`HeroVisual.tsx`, `DeptVisual.tsx`) because no licensed
photography was available. They are on-brand, but the brief asks for cinematic photography. Replace them with
royalty-free or commissioned photos that follow this direction.

**Style:** dark, cinematic, modern; turquoise/teal light accents; clean compositions; no stock clichés (no handshakes in suits,
no thumbs-up). Matches the brand guide photography page (teal interiors, teal objects, dark backgrounds).

| Slot | Size | Content |
|---|---|---|
| Home hero | 1600×1400, 4:3.5 | Remote creative workspace at dusk: laptop showing the Pixel Graphics website, desk plant, coffee mug, notebook, turquoise lamp / window light |
| Branding card | 1200×750 | Business cards & stationery on dark surface, teal accent |
| Graphic design | 1200×750 | Printed posters/brochures, overhead flat-lay |
| Social media | 1200×750 | Phone showing an Instagram grid, teal light |
| Digital marketing | 1200×750 | Analytics dashboard on screen, moody light |
| Motion | 1200×750 | Video timeline on monitor, editing setup |
| Web design | 1200×750 | Website design on a laptop/monitor |
| Consultancy | 1200×750 | Video call on laptop (no identifiable invented team members) |
| Events | 1200×750 | Event signage / exhibition stand in teal & charcoal |

Use `next/image` with WebP/AVIF output; keep each hero under ~250 KB.
